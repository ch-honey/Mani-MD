MANII-05-MD WhatsApp Pairing

Apna WhatsApp number country code ke saath enter karein. Example: 923001234567. Number ke start mein + ya spaces na dein.

Bot connection status check ho raha hai...
  1. WhatsApp open karein.
  2. Settings → Linked devices par jayein.
  3. Link a device → Link with phone number instead select karein.
  4. Yahan milne wala code WhatsApp mein enter karein.
Pairing code kisi ke saath share na karein. Sirf apne bot/server ke liye use karein.
